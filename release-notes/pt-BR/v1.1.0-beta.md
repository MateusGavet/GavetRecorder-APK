# Gavet Recorder v1.1.0-beta

## Novidades

- App multilíngue com suporte ao idioma do aparelho.
- Suporte a idioma por app no Android 13+.
- Centralização das permissões necessárias do app.
- Solicitação de permissões para câmera, microfone, localização, notificações, Bluetooth e mídia.
- Seletor explícito de dispositivo Bluetooth para OBD2.
- Correção para evitar conexão incorreta em CAR-KIT/multimídia.
- Editor de overlay com grade 9x9 e arrastar/soltar.
- Correção de persistência do layout do overlay.
- Overlay transparente e personalizável.
- Correção da aba Mapa para casar vídeos com metadados de rota.
- Integração OBD2 Bluetooth para velocidade, RPM e consumo quando suportado.
- Google Drive com envio manual e automático.
- Melhorias no salvamento de vídeos, rotas, metadados e logs.

## Observações

- Recursos OBD2 dependem do adaptador e dos PIDs suportados pelo veículo.
- A marcha é estimada por velocidade/RPM.
- Para usar OBD2, pareie o adaptador no Android e selecione o dispositivo correto no app.
- Esta é uma versão beta pública.
