# Gavet Recorder v1.1.0-beta

## Novidades

- App multilíngue com suporte ao idioma do aparelho.
- Suporte a idioma por app no Android 13+.
- Interface atualizada para inglês, português, espanhol, francês, alemão, italiano, japonês, coreano, chinês, russo e árabe.
- Editor de overlay com grade 9x9 e arrastar/soltar.
- Overlay transparente e personalizável.
- Itens configuráveis no overlay:
  - RPM
  - Velocidade
  - Mapa
  - Nome da rua
  - Marcha estimada
  - Direção
  - Consumo de combustível
  - Consumo médio
  - Km/L
- Integração OBD2 Bluetooth para velocidade, RPM e consumo quando suportado.
- Google Drive com envio manual e automático.
- Metadados, rotas e logs salvos com mais segurança.
- Aba Mapa corrigida para acompanhar os segmentos gravados.
- Melhorias no salvamento e revisão dos segmentos.

## Observações

- Recursos OBD2 dependem do adaptador e dos PIDs suportados pelo veículo.
- A marcha é estimada por velocidade/RPM.
- Esta é uma versão beta pública.
